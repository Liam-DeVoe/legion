# Notification audit of INFRA-3686

This audit lists each kind of text that reaches an agent session when the agent did not ask for it. Each row gives the producer, the trigger, the readers and the rule that picks them, whether the text starts a turn today, whether it carries what it is about, its size, its count in 47 hours of INFRA's sessions, and a verdict. Each row of a kind on the daemon's one list names the kind in backticks and its urgency for each reader. Each row that is not "fine" names the requirement of dispatch://INFRA-3686/spec that fixes it, the open issue that owns the fix, or the person's decision that leaves it.

## How it was made

- **Code.** Read at cybermonklabs/legion `main` 0316ab0dcdb9 (2026-11-16): the Legion daemon (`packages/daemon`), the Dispatch server (`packages/envoy/internal/dispatch`), the Envoy listener (`packages/envoy/cmd/listener`), the card renderer that Oh My Pi and Claude Code share (`packages/envoy-client/src/delivery.ts`, `renderInbound`, which runs in each host), and the plugins (`packages/pi-envoy`, `packages/pi-legion`, `packages/pi-shared`, `packages/claude-envoy`). The notice kinds are `validNoticeKinds` and the controller's kinds of `controllerOnlyNoticeKind`, both in `packages/daemon/internal/record/outbox.go`; the daemon's admission, workflow and outbox code write them. In the window INFRA's daemon ran a release from before cybermonklabs/legion#2539 until it booted again at 2026-11-16T22:51Z, so a row's trigger is main's and the sample's cards are that release's; where the two differ the row says so, and the measurement after the deploy compares like with like only for the kinds whose trigger is the same.
- **Urgency.** The kinds, their forms, their readers and their urgencies come from the daemon's one list on the branch of this change. In `packages/daemon/internal/texts`, `kinds.go` and `entry.go` give each kind, its form and its readers. `rules.go` gives the rule of each kind that is not `med` for every reader. The urgency of a Dispatch event type is R5's rule, which `envelope` applies (`packages/envoy/internal/dispatch/outbox/publisher.go`).
- **Measurement.** 66 transcripts of INFRA Legion roles from INFRA's session store: 12 architects, 12 implementers, 12 testers, 12 reviewers, 8 planners, 8 mergers, and the 2 controller sessions of the window; 3 of the planners hold no message in the window (two began after it, and one at 22:59:46Z with only its header entries before 23:00Z). Only entries from 2026-11-15T00:00Z to 2026-11-16T23:00Z count (47 hours). The store was read only inside read-only transactions. The daemon's own Dispatch events of the same hours come from Dispatch's event log (`GET /api/v1/events/log`), read on 2026-11-17. The scripts are dispatch://INFRA-3686/artifact/notification-measure-scripts-md; its `counts.sh`, run on 2026-11-17, gives the counts of the CI settlement, the dead letter, `artifact.changes_requested` and a person's mention receipts.
- **Sizes.** "Measured" sizes and counts come from the transcripts, and for the daemon's messages on Dispatch issues from the event log, in characters. "Counted" sizes come from the format strings in the code with realistic values, to about 3%. "Not in the sample" means the 47 hours held none.

## The totals

| What | Count | Bytes |
| --- | ---: | ---: |
| Everything the model read that it did not write, each entry once | 28,419 | 50,393,249 |
| Tool results of the agent's own calls | 21,451 | 39,910,466 (79.2%) |
| Envoy cards (messages and notices) | 5,452 | 8,720,676 (17.3%) |
| Daemon tasks | 336 | 531,755 (1.1%) |
| Plugin texts | 590 | 216,526 (0.4%) |
| **Notifications in all** | **6,378** | **9,468,957 (18.8%; 90.3% of what was not a tool result)** |

- **Turns.** 2,775 turns. 2,628 of them (94.7%) started on notifications alone. Those turns cost $3,669.63 of the $4,096.20 that all turns cost (`usage.cost.total`).
- **Turns that did nothing.** 891 notification-started turns made no tool call. They cost $207.59. The largest groups: 163 after an architect's message, 162 after a phase reminder, 149 after `phase-finished`, 88 after a Dispatch `child.status` card, 66 after an implementer's message.
- **Cold wakes.** 306 notification-started turns wrote more than half their context to the cache. They cost $911.07. The median context at the first call of a notification-started turn was 527,173 tokens.
- **Fetches.** Of 5,377 notifications that name an item, the next three tool calls read that item 794 times (14.8%).

## Verdicts

**fine**; **verbose**: fixed text, a field repeated, or a long list; **no content**: it sends the reader to fetch words that the producer had; **no act**: it starts a turn in which, by the reader's prompt, the reader starts nothing; **copy**: one act reaches the reader twice; **lost**: it can reach no session. R1 to R8 are the requirements of dispatch://INFRA-3686/spec. "Fixed by" names the requirement of this change that fixes the row.

**Urgency** is the urgency that each reader gets once this change is built (R5). On an Oh My Pi host, a `low` text waits for the reader's next turn. A `med` text starts a turn, as today. A task has no urgency: it always starts a turn. A Dispatch event that is not `low` goes at the default urgency, and it starts a turn, as today.

4. **The reminder at a finished phase.** Confirmed; dispatch://INFRA-2746 owns it.

## How to measure again

- Select top-level files (`path ~ '/sessions/--[^/]+--/[^/]+\.jsonl$'`) whose title matches `^Legion (architect|implementer|tester|reviewer|planner|merger) · INFRA-[0-9]+$`, whose `mtime_ms` is at or after the window's start, and whose path names a start before the window's end. In each role, order by `md5(path)` and take the first 12 architects, implementers, testers and reviewers and the first 8 planners and mergers. Add each file titled `Legion controller · INFRA` that the window changed.
- Read the content from `public.omp_session_files_parts` in `start_offset` order, each read inside `BEGIN TRANSACTION READ ONLY; …; COMMIT;`.
- Count only entries whose own `timestamp` is in the window. A turn starts at an assistant message whose new inputs since the last assistant message hold no tool result; those inputs are its triggers.
- The scripts are dispatch://INFRA-3686/artifact/notification-measure-scripts-md. A run after this change first adds the new texts' first lines, the daemon's list of kinds with each kind's urgency for each reader, the urgency pi-envoy recorded on each card, and the actor of each Dispatch card to `analyze.py`.
