# The expected end of every section of every decisions.md in the fixture of c-decisions-converted,
# which decision-conversion.sh reads. It is the check's own inventory, recorded before any run: the
# driver joins it with the sections the old release's Decisions read answers, and fails on a
# section it does not name and on a line no section answers.
#
# One line a section, four fields separated by a tab:
#   1. the issue: a T1 fixture by its file name under e2e/fixtures/ (acme-1042, acme-1115), or one
#      of the driver's own two issues (own-carried, own-superseded);
#   2. the section's heading, as the old release's Decisions read answers it, with {key} for the
#      issue's key in this run and {ask:NAME} for the id the replay gave the own ask NAME;
#   3. the state the section ends in (R9 of INFRA-1150, and the check's own sentences):
#        decision   a decision block of the spec, under the section's heading block id
#        unsure     such a decision whose `Unsure:` paragraph became uncertainty high and its reason
#        unplaced   such a decision the conversion could not place under one ask: it cites more
#                   than one answered ask, or one whose block stands in no document, so it carries
#                   uncertainty high and waits for a person's review
#        replaced   such a decision marked replaced, from under `## Replaced`
#        reading    a reading under the answered ask in field 4, holding the section's words
#        dropped    no block at all: the body was the answer of the ask in field 4 and nothing
#                   more, or nothing beside that ask's own block, so no reading is written and the
#                   heading's address moves to that ask's block
#   4. the source ask: for reading and dropped the one ask the section restates, for unplaced each
#      answered ask it cites (comma separated), for a decision or a replaced decision that cites one
#      answered ask the ask its from_ask names, and - for a section that cites none.
#
# A section a converter matched on text alone would drop: the two own-carried sections whose body
# is the word "Yes", the answer the person gave two other questions, cite no ask and are the
# agent's own decisions; the section that carries the reasons no ask holds is a reading. A section
# that cites an approval ask cites no answered question (the conversion reads asks of kind
# question), so it is a decision. A section under `## Replaced` is a decision marked replaced
# whatever it cites, as the architect ruled: the acme-1115 section "microVM pods with a cgroup per
# command" cites the answered ask it restates, so its decision takes that ask as its from_ask.
